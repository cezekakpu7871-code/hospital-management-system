# Secure Hospital Management System (HMS)

A modular, secure Python implementation of a Hospital Management System designed to handle patient record registration, sensitive medical data encryption at rest, role-based access control (RBAC), and appointment management.

## Key Features

- **Data Encryption at Rest:** Patient medical records are automatically encrypted prior to storage to maintain confidentiality and protect personal health information.
- **Role-Based Access Control (RBAC):** Restricts access to sensitive medical records based on user authorization (e.g., Doctors and Administrators vs. Receptionists).
- **Appointment Scheduling:** Maps registered patient records to clinical consultations cleanly.
- **Structured Error Handling:** Prevents duplicate record registration and handles invalid data queries gracefully.

## Architecture & Requirements Alignment

This system was designed based on Software Requirements Engineering principles:
1. **Security Compliance:** Ensures patient data confidentiality via modular encryption classes (`SecurityManager`).
2. **System Verifiability:** Every feature uses measurable, quantitative output verification rather than ambiguous specifications.
3. **Modularity:** Built using Object-Oriented Programming (OOP) principles for easy maintainability and extension.
